# Runs

Every reply from the runs in [SOLUTION.md](../SOLUTION.md), one file each.

`<model>/<email>__<condition>.txt`

| Condition | What went in front of the model |
|---|---|
| `A-dump-question-first` | Prompt and email, then the whole drive |
| `B-dump-question-last` | The whole drive, then the prompt and email (step 1 of the exercise) |
| `C-selected` | The matching file in [`selected/`](../selected/), then the prompt and email (step 3) |

The replies are as returned, with one exception: where a reply ended with a long note to Inês after a `---` line, five files keep the note in shortened form, in brackets. These are `opus-5-5/02-return__A`, `02-return__B`, `02-return__C` (where the note came first), `03-ponte-nova__A` and `03-ponte-nova__B`. SOLUTION.md quotes what those notes said.
